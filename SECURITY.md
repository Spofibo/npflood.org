# Security

This site is static. It does not store personal reports on a server. Drafts stay in the browser.

If you find a vulnerability in the site, the service worker, or the deploy setup, report it privately through GitHub Security Advisories on [Spofibo/npflood.org](https://github.com/Spofibo/npflood.org).

Do not open a public issue for a vulnerability. Do not invent a contact email here.

We will acknowledge a valid report and say what we will change.
